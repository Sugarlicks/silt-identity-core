# Licence status for Vietsch v0.1 pilot archive

This package collects preserved historical SILT Core v0.1 materials and subsequent non-normative implementation records. It **does not grant or withdraw** copyright licences by assembling them into an archive.

- The public repository identifies historical v0.1 material (including the AUT profile) as Apache 2.0 unless stated otherwise. The preserved historical licence text is included in `archive/v0.1/LICENSE`; the main repository has `LICENSES/Apache-2.0.txt`.
- The signed Vietsch MoU specifies publicly available project source code under Apache 2.0 and other project information under **Creative Commons**, without stating which CC variant.
- The rights holder has **not yet expressly recorded a final file-by-file Creative Commons licence grant for the proposed deposit** in these release files. Do not infer one from the mere inclusion of this note.
- A proposed licensing decision (outside this archive) suggests retaining irrevocable historical Apache permissions and, where the rights holder has authority, granting CC BY 4.0 additionally for suitable narrative material, subject to approval.
- Where a record contains third-party material, ensure separate permission/attribution as necessary. Institutional affiliations and the AUT pilot example imply no endorsement.

**Publication gate:** Confirm the rights holder's decision and add exact per-file licence notices or a licence mapping before submitting this release to Zenodo or marking it final.
