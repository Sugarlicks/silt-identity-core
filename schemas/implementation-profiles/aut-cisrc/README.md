# AUT CISRC Profile Schemas

> **Historical / transitional notice:** These schemas remain part of the AUT CISRC / Vietsch SILT Core v0.1 implementation through completion. SILT Core v0.2 is now at Freeze Candidate 1. The schemas are not v0.2 Core schemas and are not being migrated mid-stream.

This folder contains JSON schemas for the AUT CISRC implementation profile.

These schemas are non-normative and profile-specific. They apply SILT Core v0.1 concepts to a constrained AUT CISRC research-governance workflow.

They do not modify SILT Core v0.1.

Schemas in this folder support:

- authority-chain representation;
- delegation artefacts;
- revocation events;
- access requests;
- validation results.

Findings from these schemas are retained as historical implementation evidence that informed v0.2 development. Any later v0.1 → v0.2 migration or compatibility assessment is separate work after completion of the funded v0.1 implementation.
