# Schemas

SILT Core v0.2 does not publish a universal object schema that collapses the semantic architecture into one credential or payload format. The machine-readable release artefacts used to test v0.2 are in `conformance/`.

Versioned implementation-profile schemas may remain under `schemas/implementation-profiles/`. In particular, AUT CISRC remains a SILT Core v0.1 implementation profile and is not a v0.2 schema set.

Older top-level v0.1 schemas are archived under `archive/v0.1/schemas/`.
