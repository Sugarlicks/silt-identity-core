# SILT Core roadmap

## v0.2 release

The v0.2 semantic architecture is in release-candidate freeze. Remaining release work is publication and repository discipline rather than further ontology formation:

1. complete repository migration and version old material correctly;
2. complete the ecosystem-positioning companion;
3. finalise release authority, attribution and rights-chain metadata;
4. run repository CI against the release tree;
5. tag `v0.2.0`, archive the tag and mint the DOI.

A further Core semantic change requires a concrete conformance, external-mapping or implementation failure that exposes an otherwise inexpressible distinction.

## Implementation tracks

After v0.2, implementation work should prioritise a small number of high-value proof domains rather than widening Core:

- private ordering and electronic transferable instruments as a rigorous legal/commercial proof domain;
- delegated authority and agentic commerce as a commercial implementation wedge;
- plural and collective authority encounters as a separate legitimacy and co-design track; and
- targeted adapters to adjacent identity, credential, governance and authorisation systems.

## Governance

The immediate governance task is to mature the interim stewardship, contribution and IPR position as participation broadens. A future neutral or multi-stakeholder vehicle may be appropriate, but SILT should not claim institutional neutrality before it exists in practice.

## AUT CISRC

AUT CISRC remains a SILT Core v0.1 implementation profile. It will be completed and archived under v0.1 and is not on the v0.2 migration roadmap.
