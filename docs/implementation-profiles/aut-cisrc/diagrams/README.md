# AUT CISRC Diagrams

These diagrams are non-normative pilot modelling artefacts for the AUT CISRC implementation profile.

They support the implementation profile by illustrating:

- the semantic architecture;
- the use case model;
- the class/object model;
- the validation activity flow;
- the validation sequence flow.

These diagrams do not define or modify SILT Core v0.1.

Findings from the diagrams may inform later SILT Core v0.2 consideration.
