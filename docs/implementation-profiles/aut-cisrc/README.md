# AUT CISRC Implementation Profile

**Version:** SILT Core v0.1 implementation profile  
**v0.2 relationship:** historical/non-normative; no migration is planned

This folder applies SILT Core v0.1 to a constrained university research-governance workflow, using AUT CISRC as the pilot context. The underlying delegation and revocation model is not AUT-specific and may be portable across registered universities and comparable research institutions, but this material does not represent formally approved AUT institutional architecture.

The profile is being completed, tested, documented and archived under the v0.1 model against which it was built. It MUST NOT be relabelled as v0.2-conformant. Its continued presence in this repository is implementation and research evidence, not part of the SILT Core v0.2 conformance claim.

Earlier notes titled as candidate v0.2 findings are preserved as historical research material because they record what the implementation surfaced before the current v0.2 architecture was settled. They are not a migration plan.
