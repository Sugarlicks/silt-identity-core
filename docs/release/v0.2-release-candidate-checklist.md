## Freeze discipline after external review

The semantic review gate is closed.

No further semantic editing should occur before `v0.2.0` unless final mechanical validation reveals an actual contradiction, missing artefact or implementation-independent semantic defect.

Editorial, metadata and publication corrections may proceed without reopening Core. Any later semantic change should be recorded transparently as an erratum or proposed for a subsequent version rather than introduced silently.

## Website release requirement

The public website must not continue to present v0.1 concepts such as universal Capacity, Status or “authority semantics for digital action” as the current SILT Core architecture once v0.2 is released.

The v0.2 website should foreground:

> **Source → Standing → Presentation → evaluation at the encounter**

and describe SILT as a semantic architecture for mutual legibility across plural legal, customary, cultural, private, institutional and technical orders without requiring ontological collapse.

The website update should remain public-facing and concise. It should not reproduce the full normative Core or collapse the wider project into an identity / authorisation product.
