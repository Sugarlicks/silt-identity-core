# AUT CISRC implementation profile status

AUT CISRC is a **SILT Core v0.1 implementation profile**.

It was designed and implemented against the v0.1 delegation and revocation model and will be completed, tested, documented and archived in that form. It is not being migrated to SILT Core v0.2.

## Release relationship

- AUT CISRC is non-normative for SILT Core v0.2.
- Its artefacts MUST NOT be relabelled as v0.2-conformant.
- v0.1 terminology may remain where it accurately describes the implementation that was built.
- The profile may be cited as historical implementation and research evidence that informed later SILT development.
- Its presence in the repository does not expand or constrain the v0.2 Core architecture.

Any future AUT implementation using SILT Core v0.2 would be a new implementation exercise, not a required migration of the existing profile.
