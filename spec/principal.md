# Principal — v0.1 archival notice

This file is retained as a **SILT Core v0.1 specification artefact** for historical and migration reference.

The original v0.1 `Principal` model treated Principal, Capacity, Authority grant, Reliance and Binding as part of a foundational action-oriented structure. That model is **not the controlling SILT Core v0.2 architecture**.

For v0.2, the canonical semantic reference is:

[`spec/v0.2/semantic-architecture.md`](./v0.2/semantic-architecture.md)

The settled v0.2 seam is:

> **Source → Standing → Presentation → evaluation at the encounter**

SILT Core v0.2 uses a deliberately thin **Participant** referent and models **Standing** as relational and grounded in **Source**. A Participant brings the minimum relevant projection of Standing, Authority or another semantic claim into a specific encounter through **Presentation**.

`Capacity` is not retained as a universal v0.2 Core primitive. Where role, office, trusteeship, agency, representational position or another acting basis matters, its meaning is expressed through the applicable combination of Source, Standing, Authority, Presentation and Profile Expression.

Likewise, **Binding is not a universal SILT Core v0.2 conclusion**. Binding or other downstream effect remains defined by the applicable Profile Expression or other recognised normative mechanism.

There is therefore **no claim that the v0.1 `Principal` object maps one-to-one to any single v0.2 object**.

The original v0.1 contents remain available through Git history. They should be read as part of the historical development of SILT Core and, where relevant, as context for v0.1 implementations. They should not be used as normative v0.2 semantics.
