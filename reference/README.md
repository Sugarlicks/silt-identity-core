# Reference implementations

Reference code is non-normative unless expressly stated otherwise.

The AUT CISRC validator remains part of the SILT Core v0.1 implementation profile and is intentionally preserved in `reference/validators/aut-cisrc-delegation/`. The earlier standalone consent validator is archived as v0.1 material.

SILT Core v0.2 conformance is tested through `conformance/` and `ci/`; those artefacts do not create additional Core semantics.
